# DSH Mobile 设置菜单与字段清单（v0.1.0-dev.13）

## 当前导航

左侧顺序：**基础配置 / 局域网 / Cloudflare隧道 / frpc隧道 / 运行日志**。

所有菜单复用固定高度弹窗，顶栏始终显示三种网络入口的运行状态；网络菜单内的独立启用开关只修改该网络的运行配置。

### 1. 基础配置

| 字段 | 对应持久化数据 | 行为 |
| --- | --- | --- |
| 共享代理端口 | `gateway.port` | 一个 TCP 监听端口供局域网、Cloudflare 和 frpc 共用；变更后会重新建立网关和已启用隧道 |
| 局域网访问密码 | `lan.password` / `lan.hash` | 独立密码；用户主动输入新值后才更新；保留显示/隐藏与复制 |
| 公网访问密码 | `public.password` / `public.hash` | Cloudflare 与 frpc 共用；修改会令公网旧认证会话失效 |
| DSH 实例标识 | `identity` 派生 ID | 只读，不提供重置按钮 |
| 网关运行状态 | 运行时状态 | 只显示，不强行启动用户已关闭的网络 |

- 两种密码长度均为 8–64 位，旧密码原样保留，不会因切换菜单、保存端口或重启自动轮换。
- 一次调用 `POST /dsh-mobile/admin/configure`，请求体中的 `mode` 为 `base`，`patch` 支持 `port`、`lanPassword` 和 `publicPassword`；未修改密码则不发送对应字段。
- 密码和端口先完成全部校验，再一次持久化，以避免单字段验证失败造成部分提交。
- 端口必须是 1–65535；历史自动化测试通过其他管理模式允许使用端口 0 作随机端口模拟，界面不会提供 0。

### 2. 局域网

独立启停、网络接口 IP 选择、连接地址与二维码。选择 IPv4 地址并保存后持久化 `lan.preferredAddress`，网卡变化时可回退到仍可用的地址。密码和共享端口已移到基础配置。

### 3. Cloudflare隧道

独立启停、快速/命名隧道、固定域名、Tunnel Token、cloudflared 路径，以及 Cloudflare 专用 GitHub 下载源和自定义 HTTPS 前缀；连接成功后显示公网地址与二维码。共享端口和公网密码已移到基础配置。

### 4. frpc隧道

独立启停、frps 地址、控制端口、远程映射端口、映射名称、手机访问地址、frps Token、frpc 路径和 frpc 专用 GitHub 下载源；连接成功后显示地址和二维码。共享端口和公网密码已移到基础配置。

### 5. 运行日志

统一展示最新 30 条插件中文运行日志，支持复制、调整日志区高度与原位刷新。

## 向后兼容

此版本不改变 `settings.json` 的 schema（仍为 2），也不会删除旧数据。后台仍兼容原有单网络的管理请求；新版 Web 页面只通过 `base` 请求写入共用字段。

## 验证范围

已通过 Node 单元/集成模拟测试、Chromium 浏览器菜单与窗口尺寸冒烟测试；尚未在用户实际的 DSH 版本和 frps/Cloudflare 实际网络环境完成验收。
